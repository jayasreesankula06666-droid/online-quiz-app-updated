# Python Basics Quiz

A responsive quiz app made with HTML, CSS, and JavaScript.

## Features
- 10 Python programming basics multiple-choice questions
- 10-minute countdown timer
- Automatically ends the quiz when time runs out
- Instant answer feedback and explanations
- Score and percentage results
- Restart quiz button
- Responsive layout for desktop and mobile

## Run locally
Open `index.html` in a web browser.

## Publish with GitHub Pages
1. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the root of your GitHub repository.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch `main` and folder `/(root)`, then save.
